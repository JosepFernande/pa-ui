Interfaces Angular rápidas, accesibles y con estilo propio

halo-ui es una librería de componentes standalone para Angular: theming con variables CSS, soporte WAI-ARIA de fábrica y una API tipada de punta a punta.

Empezar ahora Ver componentes
$ npm install @halo-ui/angular @angular/cdk

Todo lo que necesitás para construir UI

Pensado para equipos que valoran la consistencia y la velocidad.

Accesibilidad WAI-ARIA

Roles, estados y navegación por teclado incluidos en cada componente, sin trabajo extra de tu parte.

Theming con variables CSS

Colores, tipografía, espaciados y radios expuestos como custom properties: personalizá sin tocar el código fuente.

TypeScript estricto

Componentes standalone, señales y tipado estricto de punta a punta para que los errores aparezcan en tu editor, no en producción.
