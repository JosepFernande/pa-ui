Instalación y configuración

De cero a tu primer componente en menos de 5 minutos.

  1. 1

    Instalar el paquete

    Instalá el paquete principal junto con Angular CDK, la única dependencia externa. 

    npm install @pa-ui/angular @angular/cdk
  2. 2

    Configurar el Theme Engine

    Agregá el provider en app.config.ts — con el tema por defecto no necesitás pasarle nada. 

    import {{ '{' }} providePaTheme {{ '}' }} from '@pa-ui/core';
providers: [ providePaTheme() ]
  3. 3

    Importar el CSS de Foundation

    Sumá los estilos base una sola vez, en cualquier hoja de estilos global. Si te olvidás este import, los componentes quedan sin estilo hasta que lo agregues. 

    @import '@pa-ui/core/theme.css';
  4. 4

    Usar un componente

    Eso es todo — no hay NgModules ni configuración adicional. Importá el componente standalone que necesites y listo.
