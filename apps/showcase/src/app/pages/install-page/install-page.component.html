Instalación y configuración

Instalá la librería, configurala en tu proyecto Angular y creá tu primer componente en minutos.

Requisitos previos

  • Angular 19.2 o superior
  • Angular CDK 19.2 o superior
  • TypeScript 5.7 o superior
  • Conocimientos básicos de Angular standalone components

Instalación

Instalá el paquete principal junto con Angular CDK, su única dependencia externa.

Configuración

Registrá el provider del Theme Engine en app.config.ts — con el tema por defecto no necesitás pasarle nada.

Sumá también los estilos base de Foundation en una hoja de estilos global. Si te olvidás este import, los componentes quedan sin estilo hasta que lo agregues.

Primer componente

Eso es todo — no hay NgModules ni configuración adicional. Importá el componente standalone que necesites y listo.
